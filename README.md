# Eva — AI Voice Recruiter

Голосовой AI-рекрутер, который сам обзванивает кандидатов, проводит структурированный
скрининг и передаёт отобранных живому рекрутеру. Второй канал — Telegram-агент, который
дописывает тех, до кого не дозвонились, той же персоной и сводит диалог в ту же карточку CRM.

Система работает в продакшене логистической компании. **300+ реальных звонков** обработано.

> В этом репозитории все данные обезличены: название компании-заказчика, телефоны и имена
> кандидатов заменены на примеры. Ключи и учётные данные никогда не попадали в репозиторий —
> конфигурация целиком в переменных окружения (`.env.example`).

---

## Что делает

**Голосовой канал.** Агент звонит по SIP-транку, говорит по-украински, ведёт скрининг по
шагам: опыт → география → возраст → готовность к формату работы. Распознаёт автоответчик,
держит лимиты на количество попыток и одновременных звонков, диагностирует качество линии
по SIP-кодам.

**Telegram-канал.** MTProto-userbot (не бот-API — пишет как обычный пользователь) догоняет
недозвонившихся, ведёт переписку той же персоной. Диалог склеивается с той же карточкой
кандидата — дедупликация по телефону, а для скрытых номеров по имени.

**CRM.** Карточка создаётся автоматически и двигается по воронке по вердикту агента. Внутри
транскрипт, запись разговора, AI-резюме и структурированные поля.

**Источники кандидатов.** work.ua и robota.ua — REST, где он есть, и обход Cloudflare через
системный curl там, где его нет. Резюме разбираются из PDF/DOCX/DOC.

**Отчётность.** Ежедневный сводный отчёт в Telegram: сколько набрано, сколько дошло до
рекрутера, где отвалились.

## Архитектура

```
work.ua / robota.ua ──┐
                      ├─→ scraper ─→ match ─→ scheduler ─→ call orchestrator ─→ SIP
resume PDF/DOCX ──────┘                            │              │
                                                   │              ├─→ Deepgram STT
                                                   │              ├─→ Claude (диалог)
                                                   │              └─→ ElevenLabs TTS
                                                   ↓
                                          Telegram userbot ─→ KeyCRM ─→ отчёт в Telegram
```

Шесть сервисов в Docker Compose, Caddy как reverse-proxy с TLS, APScheduler для слотов
обзвона, self-healing сверка незавершённых звонков.

## Стек

| Слой | Технологии |
|---|---|
| Backend | Python 3.12, FastAPI, asyncio, SQLAlchemy 2 (async), Alembic, Pydantic |
| AI | Claude API — диалог, классификация вердиктов, разбор звонка, tool use |
| Голос | Vapi (оркестрация), Deepgram STT (uk), ElevenLabs TTS, BYO SIP-транк |
| Данные | PostgreSQL, SQLite для локального стора агента |
| Интеграции | KeyCRM REST, Telegram MTProto (Telethon), work.ua / robota.ua, S3 |
| Инфраструктура | Docker Compose, Caddy, APScheduler, structlog, VPS |

## Запуск

```bash
cp .env.example .env      # заполнить ключи
docker compose -f deploy/docker-compose.yml up -d
```

Развёртывание под новую компанию описано в [DEPLOY_NEW_COMPANY.md](DEPLOY_NEW_COMPANY.md):
вакансии, регионы, скрипт разговора и поля CRM выносятся в конфигурацию, код не трогается.

Тесты:

```bash
pip install -e .
pytest tests/
```

## Инженерные решения, которые стоит посмотреть

**Диагностика вместо перебора.** У звонков пропадал звук в одну сторону. Вместо перебора
конфигов доказательство собиралось послойно: корреляция аудиодорожек 0.979 показала, что
провайдер подменяет входящую дорожку копией нашей же исходящей — баг на стороне вендора,
а не в коде. Итог — миграция на другой тип подключения, подтверждённая 287-секундным
звонком с MOS 4.49.

**Молчаливые отказы дороже громких.** Вебхуки отвечали 200 OK, но reverse-proxy кешировал
IP контейнера и бил в мёртвый адрес: 21 потерянная доставка и 120 нефинализированных
звонков при зелёном дашборде. Починен резолвинг и добавлена сверка, которая сама добирает
потерянные результаты.

**Модели нельзя давать абстракции.** Правило «берём правобережную Украину» модель трактовала
сама и отнесла Одессу к левому берегу — сильный кандидат получил отказ. Абстракция заменена
явным перечнем областей во всех шести местах, где она использовалась.

**Прозрачность для нетехнического пользователя.** Рекрутеры не видели, что делал агент:
карточка писала «поговорили, добираем в Telegram», хотя за этим стояли 13 неудачных
дозвонов. Статусы переписаны так, чтобы отражать реальный путь кандидата.
